### Theo Coronges

Applied Mathematics @ IE University. Building quantitative trading systems, large-scale empirical data pipelines, and native macOS/iOS software.

#### Selected Work

1. **[opportunitylab](https://github.com/imbricata/opportunitylab)** — Paper-first quantitative research and execution engine for short-lived prediction-market inefficiencies (Polymarket CLOB L2, Chainlink oracle streams, delayed-FOK fill simulation, bounded LLM contract review, and automated forward-cohort strategy promotion).
2. **[spain-mobility-internship](https://github.com/imbricata/spain-mobility-internship)** — Empirical analysis of 3.11B Spanish origin–destination trips across 3,792 districts (MITMA, INE, Foursquare), modeling distance-decayed income assortativity, spatial entropy, and socioeconomic segregation (Northeastern University, supervised by Prof. Esteban Moro).
3. **[cadence](https://github.com/imbricata/cadence)** — Native macOS and iOS planning and activity-scoring system in Swift/SwiftUI with custom PKCE Google OAuth, Google Calendar REST client, conflict-resolving Drive sync, RFC 5545 `.ics` recurrence parser, and exponentially weighted form scoring.
